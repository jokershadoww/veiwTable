# جدول منصات 🏰

موقع **"جدول منصات"** مبني بـ **Next.js 16** و **Firebase (Firestore)** بواجهة عربية RTL عصرية،
متوافقة بالكامل مع الحواسيب والهواتف والأيفون.

---

## ✨ المميزات

### بنية صفحات الموقع (تقسيم)
- **`/` جدول المنصات**: ترويسة «منصات 326» + جدول المنصات (اسم المنصة، نوع المنصة، قوة الفيلق، مارد، وأيقونات الاختام/البطايق/الجاهزية/المذهب، لاعب القلعه، الملاحظات) + بحث وفلترة حسب النوع
- **`/players` الاعبين**: صفحة مستقلة تعرض كل منصة واللاعب الحالي فيها (متاحة / مشغولة)
- **`/stats` الإحصائيات**: صفحة مستقلة تعرض:
  - **إجمالي عدد المنصات**
  - **إجمالي مذهب الثكنة** (بالمليون)
  - **إجمالي مذهب الرماه** (بالمليون)
  - تفصيل: منصات الرماه / الثكنة / خطين / لاعبين متوفرين
  - الأنواع السالبة (**-رماه** و **-ثكنة**) **لا تُحسب** في الإحصائيات
- قائمة جانبية أنيقة (درج منسدل في الهاتف) تنتقل بين الصفحات مع تظليل الصفحة الحالية
- **حقوق النشر**: تذييل «جميع الحقوق محفوظة © 2026 — omar326» أسفل **كل** الصفحات
  (المنصات، الاعبين، الإحصائيات، لوحة الأدمن، تسجيل الدخول، صفحة تسجيل اللاعب)

### النوافذ المنبثقة
- **الاختام**: دائرة مقسّمة إلى **6 خانات**، كل ختم له اسم ومستوي (يُدخل يدوياً)، والاختام مقسّمة
  إلى 4 أقسام: الثكنه / الرماه / العادية / النادرة
- **البطايق**: تبويب **SSS** و **SS**، مع مفتاح **تمتلك / لا تمتلك** — وعند الامتلاك تظهر خانة **النجومية** (حتى 6) و**المستوي** لتلك المنصة
  - في الصفحة الرئيسية تُعرض **البطايق الممتلكة فقط** (مع عدّادها في أزرار التبويب)
- **الجاهزية**: ساعات حرة، ساعات علاج، تساريع 50%، تساريع 25%
- **المذهب**: مذهب الثكنه ومذهب الرماه (بالمليون)

### لوحة الأدمن `/admin`
- تسجيل دخول: `admin` / `123456omarA` (قابل للتغيير من متغيرات البيئة)
- **المنصات**: إضافة / تعديل / حذف مع كل الحقول (أساسية + جاهزية + مذهب + اختام + بطايق + ملاحظات)
- **الاختام**: إضافة اختام وتقسيمها للأقسام
- **البطايق**: إضافة بطايق SSS/SS وتصنيفها وأقصى نجومية
- **الاعبين**: إنشاء **روابط تسجيل** ونسخها، إيقاف/تفعيل الرابط، مسح التسجيلات، حذف الرابط،
  وعرض اللاعبين المسجّلين

### صفحة تسجيل اللاعب `/register/[linkId]`
- رابط خاص يُرسل لكل لاعب، يختار منصته ويكتب اسمه
- **لاعب واحد لكل منصة في الرابط الواحد**، والمنصات المحجوزة تظهر غير متاحة
- عند التسجيل يظهر اللاعب تلقائياً في قسم «الاعبين» بالصفحة الرئيسية

## 🔌 ربط Firebase

الموقع مربوط الآن بـ **Realtime Database** (مشروع `veiwv1`).

### 1) فتح قواعد الأمان (خطوة مطلوبة الآن)
من [Firebase Console](https://console.firebase.google.com) → **Realtime Database → Rules**
الصق محتوى ملف `database.rules.json` ثم اضغط **Publish**:

```json
{
  "rules": {
    "platforms": { ".read": true, ".write": true },
    "seals": { ".read": true, ".write": true },
    "cards": { ".read": true, ".write": true },
    "links": { ".read": true, ".write": true },
    "registrations": { ".read": true, ".write": true }
  }
}
```

### 2) مفاتيح المشروع (موجودة في `.env.local`)

```bash
NEXT_PUBLIC_FIREBASE_API_KEY=...
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=...
NEXT_PUBLIC_FIREBASE_PROJECT_ID=...
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=...
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=...
NEXT_PUBLIC_FIREBASE_APP_ID=...
```

بعد نشر القواعد تتحول البيانات **اللحظية (Realtime)** تلقائياً — كل الأجهزة بنفس البيانات.

> ⚠️ قبل نشر الموقع للعامة: استبدل القواعد بقواعد محدودة (Firebase Auth + قراءة عامة للكتابة خاصة).

## 🗂️ هيكل بيانات Realtime Database (المسارات)

| المسار | الحقول |
| --- | --- |
| `platforms/{id}` | name, type, legionPower, mard, seals[6], cards{ [id]: {stars, level} } (البطايق الممتلكة)، readiness{}, gold{}, castlePlayer, notes |
| `seals/{id}` | name, category (الثكنه/الرماه/العادية/النادره) |
| `cards/{id}` | name, tier (sss/ss), classification, maxStars |
| `links/{id}` | label, active, createdAt |
| `registrations/{id}` | linkId, platformId, playerName, createdAt |
